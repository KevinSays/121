Reference

The Bastion Security teaching kit

The recurring "Bastion Security" material referenced across sessions — a fictional SOC where the student plays a newly hired Tier-1 analyst, and every threat type gets a case file. Introduced in Session 1 (threat actors) and built out further as later sessions add roles, cases, and episodes.

THREAT BOARD

Bastion Security Threat Board

The wanted-poster board — one dossier per threat actor category: MO, tools of the trade, countermeasure, threat level, and a cross-reference back to Session 1.

ATTACK LOG

Bastion Security Attack Log

Six dossiers spanning Module 3 (IP spoofing, ICMP abuse, TCP SYN flooding) and Module 4 (ARP cache poisoning, DNS cache poisoning, DHCP spoofing/starvation) — each with its MO, tools, countermeasure, and a cross-reference back to Session 2 or Session 3.

Practice

Hands-on labs

Supplementary lab worksheets that reinforce a session's content with something to actually do — capture traffic, run a tool, fill in what you find. Not a replacement for the official NetAcad labs, just a companion for the concepts covered here.

LAB

Wireshark Header Walk

Capture live traffic, find a TCP three-way handshake, and fill in a worksheet identifying every IPv4 header field on a real packet — the hands-on companion to Session 2's IP PDU Details.

LAB

Malware Case File

Research a real historical malware incident from credible sources and build a case file classifying it against Session 1's malware-type, CIA-triad, and threat-actor tables.

LAB

Phishing Triage

Four fictional messages from a Bastion Security client's inbox — not all of them are phishing. Identify sender-domain tells and psychology levers, and defend your verdict on each.

Session 1 Synthesis Review
