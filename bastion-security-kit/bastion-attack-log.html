FILED FROM THE PACKET CAPTURE ROOM

BASTION SECURITY ATTACK LOG

Six techniques that show up every time the foundational protocols get abused. None of these need a software bug — just a protocol that trusts the last thing it heard.

FILED

ARP Spoofing

AKA: ARP Cache Poisoning

LAYER: LOCAL SEGMENT
MO
Broadcasts fake ARP replies so nearby traffic gets rerouted through the attacker's machine before continuing to its real destination.
Tools of the trade
ARP cache poisoning tools, any laptop on the same local segment
Countermeasure
Dynamic ARP Inspection, static ARP entries on critical hosts
THREAT LEVEL: INTERMEDIATE ●●●○○
NOTE: no login required — ARP has no authentication at all. Being on the segment is the only prerequisite.
FILED

IP Spoofing

AKA: The Forged Return Address

LAYER: NETWORK
MO
Forges the source address on outbound packets so replies go somewhere else, or so the traffic's true origin never shows up in a log.
Tools of the trade
Crafted packets with a forged source IP
Countermeasure
Ingress/egress filtering at the network edge, authenticated routing
THREAT LEVEL: INTERMEDIATE ●●●○○
NOTE: rarely the whole attack — usually the enabling step for something bigger, like an amplification attack or a session hijack.
FILED

ICMP Abuse

AKA: Recon & Redirect

LAYER: NETWORK
MO
Pings the whole subnet to map who's alive before an attack even starts, or sends a forged redirect to reroute a victim's traffic path.
Tools of the trade
Ping sweep utilities, crafted ICMP redirect packets
Countermeasure
Rate-limit/filter ICMP at the perimeter, disable ICMP redirects on hosts
THREAT LEVEL: NOVICE ●●○○○
NOTE: often the opening move, not the payload — this is how an attacker learns the network before doing anything louder.
FILED

TCP SYN Flood

AKA: The Half-Open Pileup

LAYER: TRANSPORT
MO
Opens thousands of connections and never finishes the handshake, until the target's connection table has no room left for real traffic.
Tools of the trade
SYN flood traffic generators, botnets
Countermeasure
SYN cookies, connection rate limiting
THREAT LEVEL: INTERMEDIATE ●●●○○
NOTE: find it fast in a stack of connections stuck at SYN_RECEIVED with no matching ACK.
FILED

DNS Cache Poisoning

AKA: The Wrong Address

LAYER: APPLICATION / SERVICE
MO
Slips a false name-to-address mapping into a resolver's cache, so everyone who asks gets sent to the wrong, attacker-controlled address.
Tools of the trade
Spoofed DNS responses, racing the real authoritative answer back to the resolver
Countermeasure
DNSSEC, randomized query IDs and source ports
THREAT LEVEL: INTERMEDIATE–ADVANCED ●●●●○
NOTE: the URL bar lies — the victim typed the right name; the name just points to the wrong place now.
FILED

DHCP Spoofing / Starvation

AKA: The Fake Front Desk

LAYER: LOCAL SEGMENT
MO
Either floods the real DHCP server's address pool dry (starvation), or answers client requests first with a rogue server handing out a malicious gateway (spoofing).
Tools of the trade
Rogue DHCP server, automated lease-request flooders
Countermeasure
DHCP snooping, port security on access switches
THREAT LEVEL: NOVICE–INTERMEDIATE ●●○○○
NOTE: whoever answers first wins — DHCP has no built-in way to check whether the server handing out addresses is the real one.
