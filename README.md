# IT121 – Cybersecurity Essentials

Student-facing session review pages for IT121: lecture recaps, flashcards,
sample quizzes, worked examples, and glossaries for each session, plus the
"Bastion Security" teaching kit referenced throughout.

**Site:** start at `index.html` — it links out to every session and
reference page.

Built with plain HTML/CSS/JS, no build step. To preview locally, just open
`index.html` in a browser, or serve the folder with any static file server.
